# Tauri backend

[src](src/AGENTS.md) owns native commands, the local archive, MCP and PEC. [capabilities](capabilities/AGENTS.md) defines WebView permissions. [icons](icons/AGENTS.md) contains generated artwork.

Run `cargo test --locked -p eattura --lib` from the root. Preserve the local-first design and the OS credential store. See the root release guide for installers and signing.

# Eattura

Eattura è una libreria con lo scopo di semplificare la creazione invio e gestione delle fatture elettroniche.

Il progetto nasce con la missione di fornire un applicazione che gestisca le fatture elettroniche al SDI in maniera indipendente da fornitori di servizi di fatturazione.

Questo viene realizzato attraverso l'uso di PEC.
